# Каталог лучших игр Кибера

- Сохраняй согласованные URL, индексацию, canonical и порядок ItemList. Перепроверяй клиент и пререндер.
- Обновляй проект в рабочей ветке. Публикация в main, GitHub Pages и рабочем Кибере требует утверждения пользователя.
- Админка — локальный прототип для будущей интеграции с Ontico. Общая модель — `src/admin/model.ts`, изменения и вложения хранятся в IndexedDB. Источники игровых данных и серверная интеграция — отдельный этап.
- Проверки: `npm test`, `npx tsc --noEmit`, `npm run build`, `npm run build:pages`. Запуск: `npm run dev -- --host 127.0.0.1`.
- Актуальное состояние: `STATUS.md`, `CHANGELOG.md`, `handoff/README.md`.
