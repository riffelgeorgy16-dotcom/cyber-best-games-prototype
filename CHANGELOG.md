# Изменения

## 2026-11-25 — обновление GitHub Pages

- В форме игры убраны служебные поля. Жанры и платформы редактируются чекбоксами с поиском. В «Порядке игр» добавлен поиск для приоритета и закрепления.
- У админки есть отдельная страница в сборке Pages: `/admin/catalog/` под префиксом репозитория.

## 2026-11-25 — локальная интеграция

- Подключены готовые сегменты рейтинга и блоки релизов. Витрина, поиск и статический HTML применяют единое правило допуска игр.
- Добавлены десять разделов админки, IndexedDB, предпросмотр черновика и журнал версий. Табличный импорт проверяет данные до подтверждения. Поддержаны CSV, XLSX и архив настроек JSON.
- Экспорт настроек может использоваться клиентом и генератором HTML через `CATALOG_ADMIN_STATE`. Сборка Pages запускается на Windows.

## v0.4 - 2026-11-18
- Платформы на карточке - кликабельные бейджи; жанров на карточке 2 + «еще».
- Кнопка «Показать еще»: добавляет следующую страницу и меняет адрес.
- Черновик Clean-param для robots.txt Кибера.
- Тесты: 22 модульных, 77 сквозных.

## v0.3 - 2026-11-18
- Подборки над фильтрами - ссылки на посты редакции (интерактивное кино, инди-игры, красивая графика, зимние игры), список в `collections.json`.
- Убраны порядковые номера с карточек; карточка увеличивается при наведении.
- Убраны m.-версия и rel="alternate" (сайт адаптивный, AMP нет).
- Версия на GitHub Pages: статический HTML для 1146 индексируемых страниц фильтров - canonical, next, JSON-LD видны в исходном коде.

## v0.2 - 2026-11-18
- Сортировка: высокая/низкая оценка, по популярности, по алфавиту, сначала новые/старые (`?sort=`, noindex).
- Фильтр «Оценка»: 1-3, 4-7, 8-10 (`?rating=`, noindex).
- Оценки в 10-балльной шкале без названия источника (Metacritic 94/100 -> 9.4).
- Плашки подборок над фильтрами (ссылки на страницы фильтров).
- Кнопка «Добавить игру» и окно заявки (отправка имитируется).
- Размещенная копия всегда закрыта noindex, nofollow; расчетный robots в инспекторе и meta x-prototype-robots.
- Тесты: 22 модульных, 68 сквозных.

## v0.1 - 2026-11-17 - первая десктопная версия
- Каталог: 334 игры с тегами Кибера, 35 карточек на странице, сортировка по оценке.
- Фильтры платформа / жанр / год (одно значение на блок), счетчики, сброс фильтров, снятие одного фильтра.
- Поиск по названию с подсказками; Enter - результаты в текущих фильтрах (?q=, noindex).
- ЧПУ по таблице мета, прямые адреса, обновление страницы, назад/вперед, имитация 301 и 404.
- SEO: Title, Description, H1 из таблицы мета, хвосты пагинации, canonical, robots, prev/next, alternate моб., ItemList, BreadcrumbList.
- SEO-инспектор с проверками по правилам ТЗ.
- Снимок блоков «Главные новости» и «Свежие записи в блогах».
- Тесты: 17 модульных (в том числе 9817 страниц фильтров), 49 сквозных сценариев в браузере.
