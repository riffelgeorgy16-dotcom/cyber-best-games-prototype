О подборке

Обычную Nintendo Switch можно поставить в док-станцию у телевизора, вынуть и продолжить играть на встроенном экране. Есть и настольный режим со съёмными контроллерами. Switch Lite рассчитана на портативный режим, поэтому для неё особенно важно проверить, как конкретная игра использует контроллеры. Сценарий влияет на выбор: для коротких поездок удобны матчи и уровни, которые заканчиваются за несколько минут, а длинную RPG проще оставить на вечер.

Для компании в подборке есть Super Smash Bros. Ultimate. Участникам нужно выбивать друг друга за пределы арены, и для первой партии можно настроить правила так, чтобы никто не оказался зрителем надолго. Minecraft и Terraria подойдут, если хочется строить, исследовать и возвращаться к одному миру. Из крупных одиночных игр есть «Ведьмак 3: Дикая Охота» с длинными сюжетными линиями и Red Dead Redemption с более прямым маршрутом через задания.

Для игры вдвоём проверьте описание нужного режима на странице издания. Локальная игра на одной консоли, игра рядом на двух консолях и подключение по сети — разные возможности. Так проще заранее понять, хватит ли одной Switch и пары контроллеров на всех.
