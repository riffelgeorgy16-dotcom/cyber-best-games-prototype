## Правила, принятые в прототипе без отдельного согласования (технические)

- Порядок сегментов URL: жанр / платформа / год. Другой порядок, адрес без слеша, `?page=1`, заглавные буквы - имитация 301 на правильный адрес.
- Неизвестный сегмент, два значения одного фильтра, `?page` больше числа страниц или не число - 404.
- Пустой результат при клике на вариант фильтра с 0 игр - сообщение из ТЗ без смены URL и метатегов (вариант 1 ТЗ).
- Пустой результат по прямому адресу (слаги верные, игр 0) - то же сообщение, `noindex`, canonical на `/games/best/` (ТЗ).
- Хвост пагинации: ` - Страница N` в Title, Description, H1 (дефис вместо тире из примера ТЗ, «Страница» с заглавной).
- Для главной на страницах 2+ - отдельные Title и H1 из ТЗ.
- Шаблоны: индивидуальная строка таблицы мета важнее строки с переменными; если строки нет - резервный текст и предупреждение в инспекторе.
- Тексты мета из таблицы используются как есть (в них длинное тире - инспектор показывает предупреждение).
- Дата на карточке - первая дата выхода игры (Wikidata P577), без «Вышла:». Год фильтра - год этой даты.

## Данные

- Список игр и URL тегов: список тегов Кибера `/tags/game/` (571 тег игр).
- Атрибуты: Wikidata (дата, платформы, жанры, Steam ID) и английская Википедия (оценки, жанр, режимы игры).
- Обложки: заставки Steam по Steam ID; у игр без Steam - заглушка с названием. В артефакте внешние картинки запрещены - везде заглушки.
- Игры без платформы из списка фильтра, жанра, оценки или даты выхода в каталог не попадают (`data/diagnostics.json`).

## Открытые вопросы

- Платное добавление игр: размещение за деньги - реклама, нужна маркировка по закону о рекламе; и как оно сочетается с рейтингом «лучших».
- Диапазон оценки 1-3 сейчас почти пустой (1 игра): у игр с тегами на Кибере мало низких оценок.
- Куда уходит заявка «Добавить игру» в рабочей версии (почта редакции, форма поддержки, CMS).

- Данные из тегов Кибера (жанры, платформы, даты) отличаются от Wikidata; источником в рабочей версии должна быть CMS.
- Мобильные игры (Android/iOS) не попадают: в списке платформ ТЗ нет мобильных платформ.
- Платформы VR, Oculus Quest 3, Steam VR: в данных почти нет отметок.
- Года 2026 нет в таблице мета, только в фильтре.
